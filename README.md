Política de Privacidade e Termos de Uso do app [Alva](https://alva.app).

## Atualizar conteúdo

Source-of-truth fica em [`benunes01/alva` no path `docs/legal/`](https://github.com/benunes01/alva)
(repo privado do app). Pra publicar mudança:

1. Editar `docs/legal/*.html` no repo do app.
2. Copiar arquivos atualizados pra cá (`privacidade.html`, `termos.html`, `index.html`, `_styles.css`).
3. Commit + push neste repo. GitHub Pages republica em ~1 minuto.
